# 生成模型成本极简版

> 更新时间：2026-03-14
> 口径：
> - 中国版只写阿里云百炼可直接购买的模型
> - 国际版只写 Replicate 上可直接调用、且底层模型来源不属于欧盟国家的方案
> - 文档按 `输入 2000 Token + 输出 1000 Token`
> - 图片按 `1 张`
> - 视频按 `1 条（默认 5 秒）`
> - 音频按模型官方计费单位展示
> - AI 检测默认只返回 `200 Token` 的 `JSON` 结果（`probability`、`confidence`、`reasons`）
> - AI 检测图片默认先压到 `512 × 512`
> - AI 检测视频默认本地抽 `3` 帧后再检测
> - AI 检测音频默认按 `60 秒` 估算

> 说明：
> - 本文以 `mvp5` 当前代码中的前台模型 ID、默认模型、别名归一规则和实际执行链路为准。
> - 阿里云百炼和 Replicate 目前都更适合做“概率判别”而不是“真值鉴定”，所以这里写的是最低成本可落地方案，不是取证级方案。
> - 国际版检测只保留底层来源明确不是欧盟国家的模型，本节实际采用的是中国 / 美国 / 以色列来源模型。
> - 国际版当前已经按“每个小功能只保留 `1` 个前台模型 ID”收口；国内版仍保留默认项之外的兼容项 / 备选项。

> 项目接入同步（`mvp5`）：
> - 国内前台模型 ID（生成）：文档 `qwen-flash`、图片 `wanx2.0-t2i-turbo`、视频 `wan2.2-i2v-flash`（默认）/ `wan2.2-t2v-plus`（备选直出）、音频 `qwen3-tts-flash`
> - 国内前台模型 ID（编辑）：文档 `qwen-flash-edit -> qwen-flash`、图片 `wanx2.1-imageedit`、视频 `wan2.2-i2v-flash`、音频 `paraformer-v2-qwen3-tts-flash`
> - 国内视频生成默认链路：`wanx2.0-t2i-turbo -> wan2.2-i2v-flash`；仅 `wan2.2-t2v-plus` 走直接文生视频
> - 国内视频编辑实际链路：本地抽帧 -> `qwen3-vl-flash` 多帧摘要 -> `qwen-flash` 生成结构化编辑计划 -> `wanx2.1-imageedit` 关键帧预编辑 / 校验 -> `wan2.2-i2v-flash` 按原比例继续生成视频
> - 国内音频编辑实际链路：`paraformer-v2 -> qwen-flash -> qwen3-tts-flash`
> - 国内检测实际接入：`qwen-flash-detect -> qwen-flash`、`qwen3-vl-flash-image-detect -> qwen3-vl-flash`、`qwen3-vl-flash-video-detect -> qwen3-vl-flash`、`qwen3-omni-flash-realtime-detect -> qwen3-omni-flash`
> - 国内兼容保留：`qwen-vl-plus-image-detect -> qwen-vl-plus`、`qwen-vl-plus-video-detect -> qwen-vl-plus`（`legacy=true`，非默认值）
> - 国际前台模型 ID（生成）：文档 `openai/gpt-5-nano`、图片 `prunaai/flux.1-dev-lora`、视频 `wan-video/wan-2.2-t2v-fast`、音频 `minimax/speech-2.8-turbo`
> - 国际前台模型 ID（编辑）：文档 `openai/gpt-5-nano-edit -> openai/gpt-5-nano`、图片 `prunaai/p-image-edit`、视频 `lightricks/ltx-video-0.9.7-distilled`、音频 `vaibhavs10/incredibly-fast-whisper+minimax/speech-02-turbo`
> - 国际前台模型 ID（检测）：文档 `openai/gpt-5-nano-detect -> openai/gpt-5-nano`、图片 `openai/gpt-5-nano-image-detect -> openai/gpt-5-nano`、视频 `openai/gpt-5-nano-video-detect -> openai/gpt-5-nano`、音频 `vaibhavs10/incredibly-fast-whisper-detect -> vaibhavs10/incredibly-fast-whisper + openai/gpt-5-nano`
> - 国际音频编辑实际链路：`vaibhavs10/incredibly-fast-whisper -> openai/gpt-5-nano -> minimax/speech-02-turbo`
> - 国际视频编辑实际链路：优先上传抽帧关键帧并保持原始比例做参考重生成；若模型输入不兼容，再自动回退为原视频直编
> - 文档生成 / 编辑当前统一要求模型返回结构化 `JSON`，再由项目本地导出 `PDF / DOCX / XLSX / TXT / MD`
> - 检测结果会同时写入 `ai_tasks`、`ai_task_outputs`，并额外单独写入 `ai_detection_reports`

| 场景 | 当前接入模型 / 链路 | 价格 |
| --- | --- | --- |
| 文档生成 | `qwen-flash` | `≈ 0.0018 元 / 次` |
| 图片生成 | `wanx2.0-t2i-turbo` | `0.04 元 / 张` |
| 视频生成（默认） | `wanx2.0-t2i-turbo + wan2.2-i2v-flash` | `≈ 0.54 元 / 5 秒` |
| 视频生成（备选） | `wan2.2-t2v-plus` | 按百炼视频实际账单 |
| 音频生成 | `qwen3-tts-flash` | `0.8 元 / 万字符` |

### AI 编辑

| 场景 | 当前接入方式 | 实际链路 | 价格口径 |
| --- | --- | --- | --- |
| 文档编辑 | 直接结构化改写 | `qwen-flash-edit -> qwen-flash` | `≈ 0.0018 元 / 次` |
| 图片编辑 | 单图直接编辑 | `wanx2.1-imageedit` | `0.14 元 / 次` |
| 视频编辑 | 多帧理解后关键帧重生成 | `qwen3-vl-flash -> qwen-flash -> wanx2.1-imageedit -> wan2.2-i2v-flash` | `≈ 0.64 元 / 次起` |
| 音频编辑 | 转写 + 改写 + 重配音 | `paraformer-v2 -> qwen-flash -> qwen3-tts-flash` | `按秒数 + 字数 + 少量文本 Token` |

### AI 检测

| 场景 | 当前默认模型 ID | 实际落地模型 | 价格 | 备注 |
| --- | --- | --- | --- | --- |
| 文档检测 | `qwen-flash-detect` | `qwen-flash` | `≈ 0.0006 元 / 次` | 按 `2000` 输入 + `200` 输出估算 |
| 图片检测 | `qwen3-vl-flash-image-detect` | `qwen3-vl-flash` | `≈ 0.00035 元 / 张` | 默认值；`qwen-vl-plus-image-detect` 仅兼容保留 |
| 视频检测 | `qwen3-vl-flash-video-detect` | `qwen3-vl-flash` | `≈ 0.00105 元 / 条` | 默认本地抽 `3` 帧；`qwen-vl-plus-video-detect` 仅兼容保留 |
| 音频检测 | `qwen3-omni-flash-realtime-detect` | `qwen3-omni-flash` | `≈ 0.0172 元 / 60 秒` | 直接送音频做概率判别，包含声学特征 |

> 补充：国内图片 / 视频检测虽然还保留 `qwen-vl-plus-*` 两个 legacy 入口，但前端默认值和推荐值都已经切到 `qwen3-vl-flash-*`。
> 补充：如果文档是扫描件而不是可提取文本，国内版可退化为“前 `3` 页转图 + `qwen3-vl-flash`”；成本会高于纯文本抽取，但仍低于重新走完整 OCR + 多模型流水线。
> 补充：国内视频编辑的真实成本会随关键帧预编辑重试次数轻微浮动；`≈ 0.64 元 / 次起` 按“1 次关键帧预编辑 + 1 次 i2v 重生成”估算。

## 国际版（Replicate，且排除欧盟来源）

> 说明：国际版费用受 `token`、分辨率、时长、步数影响较大，本节不再写容易失真的单次美元估算；统一以 **当前项目实际接入模型 + 当前真实执行方式** 为准，实际账单以 Replicate 为准。
> 说明：国际版当前目标是“每个小功能只保留 `1` 个综合最优默认方案”。

### AI 生成

| 场景 | 当前保留模型 ID | 当前真实方式 | 说明 |
| --- | --- | --- | --- |
| 文档生成 | `openai/gpt-5-nano` | 直接生成结构化 `JSON`，再本地导出 `PDF / DOCX / XLSX / TXT / MD` | 与当前项目文档导出器完全一致 |
| 图片生成 | `prunaai/flux.1-dev-lora` | 单步文生图 | 当前国际版在质量、速度、可控性之间更均衡 |
| 视频生成 | `wan-video/wan-2.2-t2v-fast` | 单步文生视频，失败时自动降级最小输入重试 | 当前默认方案里速度 / 成本平衡更好 |
| 音频生成 | `minimax/speech-2.8-turbo` | 单步文本转语音 | 当前保留的国际版语音生成入口 |

### AI 编辑

| 场景 | 当前保留模型 ID | 当前真实方式 | 备注 |
| --- | --- | --- | --- |
| 文档编辑 | `openai/gpt-5-nano-edit` | `openai/gpt-5-nano` 按指令输出结构化 `JSON`，再本地导出原目标格式 | 前台是编辑别名，底层已归一 |
